# Likhit Packers and Movers

Welcome to the official web application for **Likhit Packers and Movers**, a premier relocation and logistics company based in Koppal, Karnataka. This application provides a seamless experience for customers to explore moving services, get instant quotes, track their shipments in real-time, and manage their bookings.

## 🚀 Features

- **Dynamic Booking & Quoting:** Customers can instantly request quotes for 1BHK-4BHK home shifting, office relocation, and vehicle transport.
- **Real-Time Tracking System:** Customers can enter their unique Booking ID to see a live visual timeline of their shipment (Booking Confirmed -> Packing -> In Transit -> Delivered).
- **Authentication & Profiles:** Fully integrated with **Supabase**. Customers can register via OTP, log in securely, and view their dashboard with past and active moves.
- **Automated Email System:** Integrated with Nodemailer to instantly send quote requests to the business team and auto-responder "Thank You" emails to the customers.
- **Modern UI/UX:** Built with Tailwind CSS, Lucide React icons, and a fully responsive mobile-first design.

## 🛠️ Tech Stack

- **Framework:** [Next.js](https://nextjs.org/) (App Router, Server Components)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Authentication:** [Supabase Auth](https://supabase.com/)
- **Database:** Prisma ORM / PostgreSQL
- **Email:** Nodemailer (Gmail SMTP)
- **Icons:** Lucide React

## 📦 Getting Started

First, ensure you have your `.env` file properly configured with your Supabase and Email credentials:

```env
NEXT_PUBLIC_SUPABASE_URL="https://your-project-id.supabase.co"
NEXT_PUBLIC_SUPABASE_ANON_KEY="your-anon-key"
EMAIL_PASS="your-gmail-app-password"
```

Then, install dependencies and run the development server:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the application.
