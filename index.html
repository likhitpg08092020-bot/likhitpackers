If you are seeing this page instead of the actual website, it means your GitHub Pages is currently configured to serve the source code branch (main) instead of the built website branch (gh-pages).

How to fix this:

  1. Go to your GitHub repository: likhitpg08092020-bot/likhitpackers
  2. Click Settings at the top
  3. Click Pages on the left sidebar
  4. Under "Build and deployment", look for the Branch dropdown.
  5. Change it from main to gh-pages and click Save.

Wait 60 seconds and refresh this page. The real website will appear!
